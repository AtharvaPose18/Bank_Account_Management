# Bank Account Management System
A beginner-friendly Java program that simulates basic banking operations through a menu-driven interface.

## Features
- Check account balance
- Deposit money
- Withdraw money
- Exit the program

## Technologies Used
- Java
- Scanner class for user input
- Switch-case and conditional statements

## How to Run
1. Download BankAccount.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac BankAccount.java
  
4. Run the program:
   java BankAccount
  
## Purpose
This project was created to practise Java programming concepts and understand basic banking operations.
